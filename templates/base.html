{% if sport in ('today', 'betting') %}

Every sport's model, next to the betting market. This is a statistics project, not betting advice.

{% elif sport == 'nba' %}

Probabilities come from player ratings and who's available: every player's value from how his teams did with him on the court, weighted by his expected minutes, with injuries from ESPN's report. Data from ESPN via sportsdataverse-data; betting lines from ESPN. This is a statistics project, not betting advice.

{% elif sport == 'cbb' %}

Probabilities come from a points model: offense and defense ratings for every Division I team, fitted to the last three seasons with recent games weighted most. Data from ESPN via sportsdataverse-data. This is a statistics project, not betting advice.

{% elif sport == 'cfb' %}

Probabilities come from a points model: offense and defense ratings for every team and its quarterback, fitted to the last four seasons with recent games weighted most (early in the season, starting from last season's ratings pulled toward the conference average). Data from CollegeFootballData via cfbfastR-data. This is a statistics project, not betting advice.

{% elif sport == 'nfl' %}

Probabilities come from a points model: offense and defense ratings fitted to four years of games, with recent games weighted more heavily and a rating for every starting quarterback. Data from nflverse. This is a statistics project, not betting advice.

{% elif sport == 'europe' %}

Probabilities come from a goals model of every club in Europe: attack and defense ratings from its league and European games together, recent games weighted most, with each league's strength set by the European games between leagues. Data and odds from ESPN. This is a statistics project, not betting advice.

{% else %}

Probabilities come from a Poisson model fitted to three years of results and expected goals, with recent matches weighted more heavily. Data from football-data.co.uk and Understat. This is a statistics project, not betting advice.

{% endif %}
